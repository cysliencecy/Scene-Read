# 私有书源与插图服务初版限制

日期：2026-08-11

## 目的

本文记录 Scene Read 初版扩展书源和插图服务的共同约束，作为后续实现、验收和范围控制的基线。

产品定位为“用户自有内容阅读器 + 平台审核书源”，而不是开放书源聚合平台。初版仅面向单用户私有使用，不提供书源公开目录、分享或跨用户同步。

## 实施顺序

1. 加入插图服务全局开关和每书开关。
2. 接入首个通过授权审查的中文书源。
3. 开放单用户私有 JSON 书源导入。

先建立插图任务和费用边界，再扩大书籍来源；JSON 规则引擎因安全和兼容复杂度最高，最后实施。

## 内置授权书源

初版中文全文以古籍和公版作品为主。现代中文作品只提供资料发现或本地文件导入，除非取得明确的全文授权。

一个内置书源必须同时满足：

- 有官方 API、数据下载入口或明确允许自动访问；
- 使用条款允许个人使用对应内容；
- 使用条款允许保存正文快照，而不只是在线浏览；
- 能保存来源 URL、许可说明和署名要求。

只允许查询、不允许保存全文的来源必须标记为 `metadata_only`。条款含糊的来源不得作为内置全文书源，可由维护者在私有 JSON 书源中自行配置并承担判断责任。

首个新增中文全文候选可研究“中国哲学书电子化计划”，但在完成授权证据审查前不承诺整本导入。中文维基文库继续作为现有通用中文公版/授权全文来源。

## JSON 书源使用边界

### 单用户私有模式

- 只有本机管理员可以导入、验证、启用、更新和删除书源；
- 不提供公共书源目录、分享链接或书源同步；
- 书源配置只保存在私有服务端或私有 Supabase 项目；
- 每个书源由管理员手动决定是否允许整本导入；
- 私有配置不代表来源网站或作品已经获得平台授权。

### 格式与兼容性

Scene Read 使用自定义声明式安全格式，并提供 Legado 书源的安全子集转换器。

初版支持：

- 公开 JSON API；
- 普通 HTML 页面；
- JSONPath；
- CSS Selector；
- XPath；
- 固定字符串替换、去除标签和空白归一化；
- 受限正则提取和文本替换。

初版不支持：

- 任意 JavaScript；
- 表达式求值；
- 登录流程、会员账号和 Cookie 会话；
- 动态解密或验证码绕过；
- 本地文件上传；
- 读取 App、Supabase 或其它书源凭据。

导入 Legado JSON 时，遇到脚本、登录、动态解密或其它不支持能力，必须在兼容性报告中明确标记，不能静默忽略关键规则。

## 网络与安全限制

所有书源请求和解析均由 Scene Read 服务端执行。

- 只允许 HTTPS；
- 每个书源最多声明 5 个固定域名，包括 API、正文和封面 CDN；
- 每次请求及每次重定向都重新校验域名；
- 禁止访问 localhost、局域网地址、云元数据地址和非标准端口；
- DNS 解析结果指向内网时立即拒绝；
- 不允许通过动态变量拼接新域名；
- 只允许 `GET` 和普通 `POST`；
- 允许预先声明的查询参数、表单或 JSON 请求体模板；
- 只允许安全请求头，不允许设置 `Cookie`、`Authorization`、`Referer`、`Origin` 和代理相关请求头；
- 关键词、页码、书籍 ID 和章节 ID 只能放入预先声明的位置，并进行正确编码；
- 限制请求超时、重定向次数、响应大小和请求频率。

正则规则必须限制单条长度、规则数量、输入大小和执行时间，并拒绝明显的灾难性回溯模式。单条规则失败只影响当前书源，不能阻塞整个服务。

## 导入与启用流程

JSON 书源不能在导入后立即参与正式搜索，必须依次完成：

```text
读取 JSON
→ 校验格式和危险能力
→ 检查 HTTPS 与域名白名单
→ 测试搜索
→ 测试书籍详情
→ 测试目录
→ 抓取一个章节进行正文预览
→ 展示兼容性报告
→ 管理员手动启用
```

任一阶段失败时保留错误详情，但不启用该书源。

## 搜索规则

- 只请求已启用书源；
- 同时最多请求 5 个书源；
- 单书源超时 8 秒；
- 单个书源失败不影响其它来源返回结果；
- 搜索页显示每个来源的成功、超时或失败状态；
- 连续失败的来源可以自动暂停，但不得自动删除；
- 支持只搜索一个指定书源，便于验证和排错。

同一本书的多个来源应聚合成一张书籍卡片，但必须允许展开选择具体来源和版本。规范化书名、作者和 ISBN 只用于疑似同书分组，不能自动抹平译本、修订版和章节差异。

## 正文快照与规模限制

从 JSON 书源导入时生成完整书籍快照；导入完成后从 Scene Read/Supabase 阅读，不在翻页时实时依赖第三方来源。

初版限制：

- 每本书最多 200 章；
- 最终正文最多 20 MiB；
- 必须完成章节顺序、正文和规模校验后再原子写入；
- 不支持数千章网络小说、断点续传或按批增量导入；
- 不后台静默更新正文；需要更新时由管理员显式执行“重新同步版本”。

超长连载模式需要另行设计分页目录、分批导入、断点恢复、增量更新和任务成本控制，不属于初版。

## 书源版本与删除

重复导入相同 `sourceId` 时视为书源更新：

- 新版本先保存为待验证版本；
- 重新执行搜索、详情、目录和单章预览；
- 展示域名、请求方法和解析规则差异；
- 管理员确认后才切换；
- 保留上一版用于回滚；
- 验证失败时继续使用旧版本。

删除书源时保留所有已导入书籍快照、阅读进度、候选、任务和图片。书籍详情继续显示原来源名称与 URL，并标记原书源已移除、无法重新同步。重新导入相同 `sourceId` 后可以恢复同步关联。

## 插图服务设置

### 开关模型

- 书架顶部提供全局“插图”总开关，不提供独立设置页；
- 阅读器工具栏提供当前书籍的独立插图开关；
- 全局和每书开关默认关闭；
- 全局开启后，新导入书籍自动继承开启状态，不在导入流程弹窗询问；
- 已存在书籍不因全局开关变化而批量生成；
- 关闭后保留已有候选、审计记录和图片。

私有单用户版本不弹出第三方 AI 数据发送提示，处理信息只保留在调试页。调试页应展示实际处理的书籍、章节、服务商、任务状态和审计结果。只要产品开始向其他用户分发，就必须增加首次开启时的第三方数据处理说明。

### 任务与费用边界

- 只处理用户实际打开的章节；
- 每章最多生成 1 张图片；
- 不做整本预生成；
- 同一章节任务必须去重；
- 生成或审计失败后不自动重试；
- 手动重新生成只能从调试页触发；
- 设置页显示当月任务数、成功数和失败数；
- 达到可配置的月度任务上限后停止创建新任务。

### 图片审核与 Demo 临时例外

- 正式策略要求每张 GLM 图片在发布到阅读页前通过视觉审核；审核失败、审核阻断或审核服务不可用时，图片只保留在调试记录中，不进入阅读页；
- 为完成单用户私有初步 Demo，可在 Server 启动环境显式设置 `DEMO_SKIP_IMAGE_AUDIT=true`；该开关不出现在 App 页面，也不允许由普通用户切换；
- Demo 跳过审核时仍写入一条 `provider=demo-bypass`、`auditVersion=demo-audit-bypass-v1`、规则严重级别为 `warning` 的审核记录，不伪装成真实视觉审核；
- Demo 跳过模式使用独立幂等键，避免复用此前 `audit_failed` 的不可变生成记录；
- `DEMO_SKIP_IMAGE_AUDIT` 未设置或不是精确的 `true` 时，继续强制要求 `VISION_AUDIT_ENDPOINT`、`VISION_AUDIT_MODEL` 和 `VISION_AUDIT_VERSION`；
- 初步 Demo 的图片可能包含原文事实冲突、错误人物/时代/场景、文字、水印或异常肢体，必须视为未经审核内容；
- 在向其他用户分发、公开演示或处理非测试内容前，必须关闭 Demo 跳过开关并接入真实视觉审核服务，再重新验证阻断、发布和失败状态。

关闭全局插图服务时：

- 取消尚未开始的 `queued` 任务；
- 已进入识别、生图或审计的任务允许完成；
- 完成结果正常保存，但不得继续创建后续任务；
- 再次开启时不自动恢复已取消任务，重新打开对应章节后才可按需创建。

## 初版明确不做

- 公共书源市场、书源分享和跨用户同步；
- 任意脚本执行和完整 Legado 兼容；
- 登录型、会员型和需要动态解密的书源；
- 绕过验证码、付费墙、访问控制或网站反爬机制；
- 对现代版权作品进行未经授权的整本抓取；
- 数千章连载小说的增量同步；
- 整本书自动生成插图；
- 自动无限重试或后台批量补图；
- 面向其他用户分发时静默发送正文给第三方 AI。

## 初版验收基线

- 插图全局开关和每书开关能正确阻止新任务；
- 一个通过授权审查的中文书源可搜索并按许可范围导入；
- 一个 JSON API 书源和一个 HTML 书源可通过验证预览后启用；
- 不支持的 Legado 能力会生成明确兼容性报告；
- SSRF、非 HTTPS、越权域名和危险请求头均被拒绝；
- 多书源搜索满足 5 并发、8 秒超时和部分成功；
- 200 章和 20 MiB 边界均有自动化测试；
- 导入后删除书源不会删除书籍快照；
- 插图服务只处理打开的章节、每章最多 1 张且不自动重试。
- 私有 Demo 可显式跳过图片审核且留下可追踪标记；默认和正式环境仍必须审核后发布。

## 2026-08-11 初版实现状态

- 已实现插图全局/每书开关、月度上限和统计、排队任务取消、服务端任务门禁及每章最多 1 图；
- 已完成中文书源授权核验，拒绝接入禁止自动下载的 Chinese Text Project，接入固定 MIT 快照的 `chinese-poetry/chinese-poetry` 审核目录；
- 已实现 Scene Read schema、Legado 安全子集兼容报告、版本化导入、四阶段预览、手动启用/旧版本切换、删除保留书籍快照；
- 已实现 JSON/HTML、JSONPath/CSS/有限 XPath、有限正则清洗，以及 HTTPS、标准端口、最多 5 域名、DNS/私网/元数据地址、重定向、请求头、8 秒超时、20 MiB 和 200 章限制；
- 私有书源管理入口只在开发环境的设置页显示，普通构建不展示；
- 图片审核默认强制执行；私有 Demo 可通过仅服务端环境变量临时跳过，跳过结果带 `demo-bypass` 审核标记；
- 新增数据库表和列位于 `supabase/schema.sql`；远程环境已于 2026-08-12 执行最新 schema，并通过设置、私有书源版本和整本导入的跨重启持久化验证。
