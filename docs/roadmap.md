# 项目路线图

## v0：App UI 骨架

目标：把已确认的手机高保真原型变成可运行 App。

范围：

- 初始化 React Native + Expo Dev Client 项目
- 搭建基础导航
- 实现书架页
- 实现导入页
- 实现风格选择页
- 实现阅读页
- 使用 mock 数据
- 不接后端

完成标准：

- App 能在开发环境中运行
- 能从书架进入阅读流程
- 阅读页能展示正文、生成中占位卡片、已生成插图卡片

## v1：本地阅读体验

目标：让 App 具备更接近真实阅读的本地体验。

范围：

- 本地 mock 书籍数据结构
- 章节列表
- 阅读进度
- 字号和主题基础控制
- 图片缓存占位逻辑

完成标准：

- 用户可以在 App 内完成一段连续阅读体验
- UI 状态稳定，不依赖后端

## v2：后端基础骨架

目标：搭建业务 API 和数据结构。

范围：

- Node.js / TypeScript API
- Supabase 项目连接
- 数据表设计
- books / chapters / generation_tasks 基础接口

完成标准：

- App 可以从 API 获取书籍、章节和任务状态
- 后端结构支持后续 AI Worker 接入

## v3：本地文件导入

目标：支持 TXT / EPUB 导入和基础章节处理。

范围：

- 文件选择
- TXT 解析
- EPUB 解析
- 章节拆分
- 本地或云端保存章节

完成标准：

- 用户可以导入一本 TXT / EPUB
- App 能展示章节并进入阅读页

## v4：AI 场景识别

目标：用 Python Worker 跑通章节到场景候选。

范围：

- Python Worker
- 场景变化识别
- prompt 生成
- 结果写入数据库

完成标准：

- 一个章节能生成场景候选和 prompt
- App 可以展示生成中和完成状态

## v5：图片生成闭环

目标：生成图片并插入阅读页。

范围：

- 生图 API 接入
- 图片保存到 Supabase Storage
- scene_images 数据回写
- App 展示完成图片

完成标准：

- 用户导入章节后，可以看到真实生成的插图出现在阅读页中

## v6：网上书籍检索导入

目标：扩展公开版权或授权书源。

范围：

- 云端搜索接口
- 书源接入
- 元数据标准化
- 导入到书架

完成标准：

- 用户可以搜索并导入一个公开版权或授权书籍
