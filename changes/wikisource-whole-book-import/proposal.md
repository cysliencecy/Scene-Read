# 中文维基文库整本导入

## Why

当前在线书库仅接入 Project Gutenberg，中文藏书数量有限，且无法满足用户搜索和阅读中文公版作品的需求。项目需要新增适合中文内容、具有公开接口且来源与许可可追溯的书源，使用户能够从统一搜索入口找到中文作品并将完整章节导入现有书架与阅读流程。

## What Changes

- 新增中文维基文库书源，通过官方 MediaWiki API 搜索作品和获取正文。
- 将在线书库搜索改为多书源聚合，同时查询中文维基文库与 Gutenberg，并在结果中标明来源。
- 只向用户展示可识别为整部作品的维基文库结果；章节子页归并到所属作品，不作为独立书籍结果。
- 导入维基文库作品时，以作品主页为书籍，以有序章节子页为章节，整本持久化后进入阅读页。
- 使用 MediaWiki 的 `zh-hans` 语言变体获取书名、章节标题和正文，保存为简体中文。
- 保存书源标识、原始页面地址及许可归属信息，并对同一来源作品去重。
- 单本导入最多处理 200 章、20 MB 正文；超过限制时返回明确错误，不产生部分书籍。
- 为多书源搜索、章节发现、简体正文解析、顺序导入、去重和限制行为增加自动化测试。

## Scope

### In Scope

- 中文维基文库作品搜索。
- Gutenberg 与中文维基文库统一搜索结果。
- 维基文库整本章节发现、排序、简体转换和持久化。
- 移动端书源标识、导入状态及错误信息。
- 数据库和共享类型对 `wikisource` 来源及许可信息的兼容。
- 以《红楼梦》作为真实接口验收样例。

### Out of Scope

- 现代版权书和商业授权书源。
- 用户选择部分章节或单页导入。
- 阅读时繁体、简体切换。
- 编辑维基文库正文或向维基文库回写内容。
- 新建独立后台任务队列；首版沿用现有在线导入请求流程。
- 为维基文库作品生成或抓取非必要封面。

## Impact

- `server`：新增维基文库 provider、多书源编排、整本解析与导入分派。
- `mobile`：扩展在线书籍类型、统一结果来源标识及维基文库错误提示。
- `supabase`：扩展书源约束和许可元数据，保持现有 Gutenberg 数据兼容。
- `docs`：记录新增书源、配置、限制、许可归属和验证结果。
- 外部依赖：只使用中文维基文库官方 MediaWiki API，不引入商业 API 密钥。

## Capabilities

- `online-book-search`：从单一 Gutenberg 搜索升级为多书源聚合搜索。
- `wikisource-catalog`：识别维基文库整部作品及其章节结构。
- `online-book-import`：按书源分派并原子化导入完整中文作品。
- `source-attribution`：保留来源页面和许可归属信息。
- `import-safety`：执行章节数、正文大小、超时、来源域名和重复导入限制。
